# Next.js reference

This folder contains the original Next.js App Router project, preserved for reference while migrating to TanStack Start.

## Contents

- `app/` — App Router pages, layouts, and route components
- `components/` — UI components (shadcn/ui) and shared components
- `content/` — MDX blog content
- `public/` — Static assets
- `config/`, `hooks/`, `lib/`, `types/` — Supporting code
- Config: `next.config.js`, `content-collections.ts`, `package.json`, etc.

## Run the old app (if needed)

```bash
cd nextjs-reference
pnpm install
pnpm dev
```
